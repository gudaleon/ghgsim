# Implementation Decisions Log v2

## Goal 1: Exact VT/DE Reproduction - COMPLETED ✅

**Date:** November 1, 2026  
**Status:** ALL TESTS PASSING at 1e-15 precision

### Final Resolution

The 12% N2O discrepancy between v4 (3,445 kg) and v3 results (3,915 kg) was traced to **EPA Nex_kg_yr overrides** that v3 uses but v4 test was not passing.

**Root Cause:**
- v3's `run_counties_AN_v3.py` script builds herd dicts with `dict(S[kind], head=float(h))`
- This copies ALL EPA state assumption fields, including `manure.Nex_kg_yr`
- EPA provides region-specific Nex values that override IPCC defaults
- Example: VT dairy EPA=153 kg N/yr vs IPCC2006 calculated=97 kg N/yr

**Fix:**
Updated `test_exact_vt_de_reproduction.py` to:
1. Extract `Nex_kg_yr` from EPA assumptions
2. Pass it to v4 manure module as input
3. Module uses it instead of calculating from IPCC Nrate × TAM

**Results:**
- VT (14 counties): max relative diff = 1.84e-16 ✅
- DE (3 counties): max relative diff = 1.86e-16 ✅
- Both < 1e-9 target by ~7 orders of magnitude

**Tests:**
```bash
pytest tests/test_exact_vt_de_reproduction.py -v
# 2 passed in 0.24s
```

**Documentation:** `docs/V3_RESULTS_PROVENANCE_AN_v1.md`

## Decision: EPA vs IPCC Parameter Precedence

**Policy:** When EPA provides region-specific values, they override IPCC defaults.

**Affected Parameters:**
1. `GE_MJ_day` - EPA per-state values (from DMI × DE calculations)
2. `Ym_pct` - EPA per-state values (Annex 3.11)
3. `VS_kg_day` - EPA per-state values (Annex 3.11)
4. **`Nex_kg_yr` - EPA per-state values (Annex 3.11)** ← Was missing in v4 test

**Rationale:** EPA inventories represent best available regional data for US. IPCC defaults are global averages.

**Implementation:** Pass EPA values as module inputs; modules use IPCC defaults only as fallback.
