# DECISIONS_AN_v25 — APSIM soil, drainage and borrowed-parameter sensitivity (Iowa)

Carries forward DECISIONS_AN_v24. All runs are consistency checks, not validation.

- **D25.1 Main soil unchanged.** SSURGO Webster (Boone County, IA) with APSIM SoilWater stays the main APSIM case (author decision D1).
- **D25.2 Tile drainage needs SWIM.** APSIM NG represents tile drains only through SWIM3 + `SwimSubsurfaceDrain` (Hooghoudt). Swim3 settings and solute transport parameters (D0, Exco, FIP) are copied from APSIM's documented tutorial `Examples/Tutorials/SWIM.apsimx`, node "HowToAddTileDrainage"; Salb and the curve-number fields come from our SoilWater node. A 100 mm LayerStructure is used for the SWIM nodes (numerical resolution; no soil property changed).
- **D25.3 Drain geometry.** DrainDepth 1200 mm, DrainSpacing 28 500 mm: Nashua, IA tile-drained plots, Malone et al. 2007, Geoderma 140, 310–322, doi:10.1016/j.geoderma.2007.04.014 (Crossref-checked; same values in the Nashua dataset paper, doi:10.2489/jswc.67.6.502). DrainRadius 150 mm as in the APSIM tutorial. Klat = SSURGO ksat_r of the horizon at drain depth × 86.4 (mm/d). ImpermDepth = base of the SSURGO profile (2000 mm; SSURGO lists no restrictive layer).
- **D25.4 Lower boundary cases.** SWIM's default free (unit-gradient) base drains the profile before any perched water table forms, so the tile case is run over APSIM's documented "seepage" base (tutorial "HowToSetASeepageLowerBoundaryCondition") with a no-drain twin (`webster_seep`). `webster_swim` keeps the free base to separate the change of water model.
- **D25.5 Result: the drain carried no water.** With SSURGO properties and NASA POWER weather, the simulated water table never rose above the 2.0 m profile base in `webster_tile`, so tile flow was 0 mm/yr and the case equals `webster_seep`. Reported as is; no parameter was tuned to force drain flow.
- **D25.6 Undrained upper bound.** `webster_wt` fixes a water table at 660 mm (documented "potential" base, tutorial "HowToSetAWaterTableLowerBoundaryCondition"); 660 mm is the SSURGO cosoilmoist 'Wet' top depth for this Webster component averaged over 12 months (66.2 cm, rounded; `data/apsim_site_iowa_AN_v2/ssurgo_cosoilmoist_AN_v1.json`). A fixed-head base cannot be combined with drains (tested: >1,400 mm/yr tile flow fed from the base), so no tile run is made on it.
- **D25.7 Clarion.** SSURGO Clarion loam, Bemis moraine, 2–6% slopes (well drained), same county, APSIM SoilWater, same management and weather.
- **D25.8 Borrowed APSoil 900 parameters (author decision D2).** Kept and disclosed. One-at-a-time sensitivity: initial NO3/NH4 ×0.5 and ×2; FBiom ×0.5 and ×1.5; FInert ×0.75 and ×1.25 (capped at 0.99). Each case has its own 0 N control for the EF.
- **D25.9 Outputs.** `results/apsim_AN_v3/`, `results/apsim_crop_sensitivity_AN_v3.csv` (scripts `run_apsim_crop_AN_v3.py`, `compare_apsim_crop_AN_v3.py`, `fetch_iowa_soils_AN_v2.py`, `fetch_iowa_watertable_AN_v1.py`). Reported in SI Table S10; no new main display item.
