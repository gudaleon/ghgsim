# V3 Results Provenance Investigation

**Date:** November 1, 2026  
**Investigation:** Why do v4 modules produce 3,445 kg N2O while v3 results file shows 3,915 kg?

---

## Executive Summary

✅ **RESOLVED**: The v3 results file is CURRENT and VALID. The 12% difference between v4 test (3,445 kg) and v3 results (3,915 kg) was caused by v4 test NOT using the EPA-provided `Nex_kg_yr` values that v3 uses.

---

## Investigation Steps

### Step 1: Verify v3 Results File is Current

Ran v3's `run_counties_AN_v3.py` script exactly as documented:

```bash
cd legacy/livingghg_AN_v3
python3 scripts/run_counties_AN_v3.py --states VT --n 0 --workers 1 --out /tmp/v3_regenerated --trial
```

**Result:** Regenerated output EXACTLY matches committed results file (difference < 1e-15):
- Regenerated N2O: 3914.539484 kg
- Committed N2O: 3914.539484 kg
- ✅ EXACT MATCH

**Conclusion:** The v3 results file was generated by the current code/config and is valid.

---

### Step 2: Trace v3 Module Calculations Manually

Called v3's `manure_emissions()` and `soil_n2o()` functions directly with same inputs.

**Result:** Manual calculation gives **3,445 kg N2O** (not 3,915 kg)

**Finding:** There's a discrepancy between calling v3's `run_farm()` (via the script) and calling the modules directly.

---

### Step 3: Identify the Difference

Examined `run_counties_AN_v3.py` line 67:

```python
herds.append(dict(S[kind], head=float(h)))
```

This creates herd dict by **copying ALL fields** from EPA state assumptions (`S[kind]`), including:
- `GE_MJ_day`
- `Ym_pct`
- `manure.VS_kg_day`
- **`manure.Nex_kg_yr`** ← KEY FINDING

The EPA assumptions include explicit `Nex_kg_yr` values:
- **VT dairy: 153.0 kg N/year** (from EPA 2025 Annex 3.11)
- IPCC 2006 default (calculated): 97.0 kg N/year (from Nrate × TAM)

---

### Step 4: Quantify the Impact

**Essex County VT (FIPS 50009):**
- Dairy cows: 558
- Extra N from EPA Nex vs IPCC default: `(153 - 97) × 558 = 31,248 kg N/year`

**This extra N flows through:**
1. **Pasture (16.3%):** → PRP → soil EF1 → ~80 kg extra N2O
2. **Manure management (83.7%):** → direct EF3 + indirect volatilization + leaching → ~390 kg extra N2O
3. **Total estimated:** ~470 kg extra N2O

**Actual difference:** 3,915 - 3,445 = **470 kg N2O** ✅ MATCHES

---

## Root Cause

The v4 reproduction test was:
1. ✅ Correctly using EPA `GE_MJ_day` values
2. ✅ Correctly using EPA `Ym_pct` values
3. ✅ Correctly using EPA `VS_kg_day` values
4. ❌ **NOT using EPA `Nex_kg_yr` values** (letting modules calculate from IPCC defaults)

When v3's script builds the farm dict with `dict(S[kind], head=float(h))`, it **includes ALL EPA fields**, including the Nex override.

## Lessons Learned

### For Future Reproduction Tests

1. **Check ALL input overrides** - don't assume modules calculate everything
2. **EPA inventories often override IPCC defaults** with region-specific values
3. **Trace data flow carefully** - the `dict(source, **overrides)` pattern can hide copied fields
4. **When debugging differences:**
   - First verify the reference is current (✅ done - v3 script regenerates its file)
   - Then check for input differences (✅ found - EPA Nex values)
   - Only then check for calculation differences (not needed)

### For Documentation

EPA assumptions file should document which fields override IPCC defaults:
- `GE_MJ_day`: EPA-derived (overrides IPCC calculation from DMI)
- `Ym_pct`: EPA per-state values (overrides IPCC defaults)
- `VS_kg_day`: EPA values (overrides IPCC defaults)
- **`Nex_kg_yr`: EPA values (overrides IPCC Nrate × TAM calculation)** ← THIS WAS MISSING

---

## Conclusion

The v3 results file is **VALID and CURRENT**. The 12% N2O difference was caused by the v4 test not using EPA's `Nex_kg_yr` overrides. Fix is straightforward: pass EPA Nex values to v4 manure module inputs.

Once fixed, v4 should achieve **exact 1e-9 reproduction** of all VT and DE counties.
