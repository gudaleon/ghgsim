# data_us (v3) - sourced US inputs
- epa_cattle_state_AN_v3.csv: EPA (2025) Inventory of U.S. GHG Emissions and Sinks 1990-2023 (EPA 430-R-25-003), Annex 3.11-3.12, tables A-128, A-132, A-133, A-134, A-138, A-139, A-142, A-156, A-157 (2022 values; EPA notes several tables were not updated for the 1990-2023 edition). The annex PDF was read from the FOIA release mirror https://ghgi.cgs.umd.edu/Web%20Content/FAQ%20Files/US-GHG-Inventory-2025-Annexes.pdf ; the main text is on epa.gov (https://www.epa.gov/system/files/documents/2025-04/us-ghg-inventory-2025-main-text.pdf). GE_MJ_day is DERIVED by inverting IPCC Eq 10.21 with EPA EF and Ym (it reproduces EPA's state EF exactly). MA VS/Nex were split across two text lines in the PDF and were entered by hand from the same table row.
- usgs_falcone2021_county_N_2017_AN_v3.csv.gz: Falcone (2021) doi:10.5066/P9VSQN3C (CC0/public domain); farm fertilizer N 2017 and manure N excreted 2017 by animal group. This is the latest year; the USGS catalogue lists no newer release.
- crop_residue_ipcc2019_AN_v3.csv: IPCC 2019 Table 11.1a and USDA ERS AH-697 bushel weights.
- Cross-check: USDA TB1939 (Hanson, Itle & Edquist 2024, Ch.4) recommends Ym 6.5% for pasture beef cows (matches EPA A-138). For dairy it recommends the Niu et al. (2018) and Moraes et al. (2014) empirical equations, which are not implemented here (candidate fork).
